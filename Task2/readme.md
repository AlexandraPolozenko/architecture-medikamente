### Как данные хранятся:

Данные будут храниться в БД PostgreSql, которая удовлетворяет требованиям:
- безопасность: поддерживается шифрование
- масштабируемость: поддерживается репликация


### Периоды и условия уничтожения конфиденциальных данных после обработки:

Данные имеют привязку к клиенту и могут быть удалены по его запросу или в случае отсутствия активности
в течение определенного количества лет.

### Какие способы защиты данных используются при хранении и передаче данных.:

- при хранении данные шифруются. 
- при передаче между системами и наружу используются только шифрованные каналы - HTTPS. 
- при передаче данных третьим лицам используется обфускация и/или обезличивание.
