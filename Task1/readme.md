## Аудит

## Проблемные зоны
- Журналы приёма, перс данные пациентов, их платежи, мед карты, анализы ведутся в файлах Excel или хранятся в виде сканов, на общем диске без доп защиты.
- Данные в указанных документах обрабатываются вручную, потоки данных между IT-продуктами никак не контролируются.
- Все сотрудники имеют доступ ко всему.
- Отсутствует журналирование действий сотрудников над данными.
- Не реализованы практики минимизации данных, их удаления по запросу и истечению срока.
- Ограничения по передаваемым данным обусловлены только бизнес-процессами компании


## Список данных и способы их защиты
Персональные данные (ФИО, контанты и пр) - шифрование, тегирование
Результаты анализов - обезличивание, тегриование
Данные о приемах (записи, результаты обсследований) - обфускация
Финансовые данные - шифрование


## Механизм тегирования
Теги:
PDn - персональные данные
Medical - данные обследований
Confidential - конфиденциальные


## Инструменты
Для тегирования предлагается использовать DataGrail, т к компания небольшая и его внедрение будет несложным. Умеет обнаруживать персональные данные
и отслеживать их путь в реальном времени.

Для шифрования можно использовать Transparent Data Encryption (TDE) для базы данных.

И внедрить ролевую модель для контроля доступов.
